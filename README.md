## ✨ Interactive macOS Portfolio Apps

- 🖥️ **macOS Desktop Experience:** Authentic login screen with user avatar ("M"), top menubar with working "About This Mac", Wi-Fi toggle, battery indicator, clock, and Control Center.
- 📝 **Notes App:** Full resume details formatted as Apple Notes (About Me, Accelryde Experience, ALASKA & CORTEX Projects, Technical Skills, Achievements, DTU Education).
- 💻 **Terminal:** Interactive macOS zsh terminal (`manmeet@macbook-pro ~ $`) supporting commands: `help`, `about`, `experience`, `projects`, `skills`, `education`, `achievements`, `contact`, `resume`, `whoami`, `ls`, `clear`, `date`, `echo`.
- 🌐 **Safari:** Customized Apple browser with SNS bookmarks, quick access to GitHub, LinkedIn, LeetCode, and project overviews.
- 🧑‍💻 **VS Code:** Interactive IDE simulator with code viewer, file tree explorer (`alaska/dijkstra-router.ts`, `cortex/vision_locator.py`, `telemetry/compression.ts`, `resume.json`), copy code functionality, and status bar.
- 🐙 **GitHub:** Built-in GitHub profile window showing pinned repos (**ALASKA**, **CORTEX**, **douglas-peucker-telemetry**, **competitive-programming**) with stars, forks, and tags.
- 📬 **Mail:** Native macOS Mail client with welcome message from Manmeet, commendation letter from Accelryde Technologies, DTU standing, and an interactive message compose pane.
- 🚀 **Projects (Website):** Production-grade project showcase for ALASKA, CORTEX, Accelryde Telemetry, and Reflect DTU.
- ⚙️ **System Settings:** About This Mac specifications, User Profile (Manmeet Singh), and appearance settings.
- 🎵 **Spotify Music Player:** Working lofi music player with playback controls.
- 🕹️ **Snake & Weather & FaceTime:** Interactive bonus utility apps.

## 🚀 Running Locally

1. Install dependencies:
```bash
npm install --legacy-peer-deps
```

2. Run development server:
```bash
npm run dev
```

3. Build production bundle:
```bash
npm run build
```
